### Skills: HTML & CSS

### Description:
- The YouTube Homepage project is a front-end UI clone created using pure HTML and CSS, designed to closely replicate the visual layout of YouTube’s homepage. The goal of this project was to practice and improve core web development fundamentals during the early stages of learning HTML and CSS.

- This project focuses entirely on structure, styling, and responsiveness, without implementing any functional logic such as button clicks or JavaScript interactions. Key UI elements such as the header, sidebar, video grid layout, thumbnails, and text alignment were carefully designed to match the real platform’s layout.

- By building this clone, I gained hands-on experience with:
    1. Semantic HTML structure
    2. CSS Flexbox and Grid for layout design
    3. Responsive design principles
    4. Spacing, alignment, and typography consistency
    5. Real-world UI replication from an existing product

- This was a solo project, and it served as a foundational step in my front-end learning journey, helping me understand how large-scale websites structure their layouts before moving on to interactivity and advanced frameworks.
